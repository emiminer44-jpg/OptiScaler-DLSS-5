## Getting Started
1. Drop the zip next to the game exe.
2. Rename `OptiScaler.dll` as the wiki says (`dxgi.dll` etc).
3. Launch. Press Insert.
4. Pick input / output upscalers.
5. Notes in `files/notes/`.

## FAQ

**FSR4 watermark?**
Enable it. Unsupported GPUs silently fall back to FSR3.

**RDNA2 Windows?**
Stay on FSR 4.0.2c. 4.1.1 ghosts on driver compile.

## Requirements
Windows 10/11 x64. DX11 / DX12 / Vulkan title with DLSS2+ / FSR2+ / XeSS.
